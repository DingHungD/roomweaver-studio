# Render fallback assets

Owned by the reusable visualization engine. `manifest.json` records source, license and SHA256. `city-sky.exr` is the unchanged distribution copy of the CC0 asset already recorded in `examples/from-3d/assets/manifest.json`; the core does not depend on the example directory or a client case. It is bundled in Python wheels for offline replay. Preserve it for renders referencing illustrative exterior settings. It is not a photograph of the user's site and does not establish site orientation or real surroundings.

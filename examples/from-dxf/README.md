# 入口二：DXF → 平面確認 → 概念 3D

上傳 **[project04-plan.dxf](project04-plan.dxf)**。ASCII DXF R2013、世界 XY 平面、毫米，僅含 LINE／封閉凸 LWPOLYLINE。來源為 Project04 電子平面之教學衍生版。

1. 「01 匯入」選空案件 →「從電子平面建立」→ 選擇 DXF。
2. 圖面單位保持 **毫米**。預期 69 個元件：31 段牆、4 片地板、5 個門洞、5 個窗洞、24 個家具區域。四片地板合成凹形室內範圍；不是四個房間。
3. 檢查用途。圖層已使用 wall／floor／door／window／furniture；名字僅提供建議，不取代確認。
4. 可先採預設教學高度建模。要重現本次測試，按 [settings.md](settings.md) 在右側選元件、填牆厚及家具高度，再「保存並檢查平面」。DXF 本身沒有這些 3D 高度。
5. 點「保留原配置，前往建模」，勾選建模範圍確認 →「確認平面，建立 3D」。不需啟動 Agent。
6. 完成後在 02 編輯檢查、移動家具，配置光源與觀看點，再出圖。

輸出為概念模型：家具仍為占位區塊，窗有簡易框，門為開口，不會自動套用入口三的精細家具。圖面中心線範圍 8.105 × 6.574 m；模型生成時會平移至近原點，原始 DXF 不變。

## 重建與來源

在 repo 根目錄執行 `python examples/from-dxf/build_plan.py`，會重新產生本 DXF 和入口一 PNG。`layout.json` 保存轉錄座標、教學家具、估計高度及來源雜湊，並供入口三重建使用。它不是應用的隱藏辨識答案；UI 匯入只讀使用者選擇的檔案。

原案件保留的 1 mm 尺寸疑點不在範例中默認為已解決；本例沿用該電子轉錄座標，僅驗證工具流程，不用於施工驗收。

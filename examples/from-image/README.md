# 入口一：圖片 → 平面確認 → 概念 3D

上傳 **[project04-plan.png](project04-plan.png)**。这是由 Project04 電子平面重繪的清楚圖片，用於練習圖片入口；不是原始手繪，也不能代表模糊手繪的辨識成功率。

1. 在「01 匯入」選擇空案件，點「從圖片建立」，選擇 PNG。
2. 連接本機 Codex、選擇可用模型。把 [context.txt](context.txt) 貼到「圖面補充說明」，再按「請 Agent 辨識」。這會使用訂閱額度。
3. 等待整圖盤點與局部複核，進入平面確認。先核對單位、比例、門窗及家具；原圖可標 A／B 點回答疑點。
4. 用「確認紀錄」記錄你已確認的數字、端點與教學假設，再請 Agent 修正。本圖可對照 [範例作者核對紀錄](confirmations.md)，不要直接把全部疑點設為略過。
5. 保存並檢查。未通過時 UI 會說明建立 3D 的阻擋原因。可保留原配置，或選用 AI 空間配置。
6. 勾選建模範圍確認，按「確認平面，建立 3D」，完成後進入 02 編輯。

## 可核對的內容

- 5 個門洞、5 個窗洞、24 個家具區域。牆分段方式可能不同，不能只比較牆數判定辨識正確。
- 外圍牆中心線範圍 8.105 × 6.574 m。這不是所有牆體的最外緣尺寸。
- 圖上 2.737、2.977、3.174 m 各有端點；按數字校正，不以印刷大小或文字寬度估尺寸。
- 黑色為牆／柱、橘色為門洞、藍色為窗洞、綠色為家具。開口線不是新牆。
- 牆高 2.8 m、門高 2.1 m、窗台 1 m／窗高 1.3 m 是教學設定；未標註的尺寸仍為估計。

需要精確且可重播的端點時，請使用入口二 DXF。此 PNG 是同一套範例的辨識練習，不宣稱能免確認還原全部尺寸。

重建：在 repo 根目錄執行 `python examples/from-dxf/build_plan.py`。來源、所有者與清理規則見 [上層說明](../README.md)。

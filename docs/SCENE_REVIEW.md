# 整屋試圖、看圖與受控修正

此功能屬於共用 Studio 出圖流程，不依賴 Project03／Project04 腳本。入口在「03 整合輸出」，勾選「整屋試圖 → Agent 看圖 → 自動修正重驗」，再沿用建立工作、確認渲染的按鈕。

## 使用與結果

- 先保存並確認編輯，至少設定一個觀看點。整屋檢查涵蓋**全部已設定觀看點及方向**，不代表沒有拍到的地方也已驗收；重要空間應各自設定鏡位。
- 勾選後才使用本機 Codex 登入呼叫雲端模型，傳送這次試圖、物件摘要、實際尺寸及照明／鏡位資料。不自動切換付費 API。未勾選時維持原有出圖流程。
- 每輪以真實 Cycles 產生 1024×512 全景與 640×480 效果圖，至多三輪；每六張原尺寸圖為一批，要求逐張回報，保留圖片雜湊、Agent 模型版本與 thread／turn。
- 修改後重新渲染並重看；無法定位物件的問題也保留。未知尺寸不偽裝成已確認，待確認項目不因下一輪未再提到就消失。
- 家具／結構疑點會再產生原生構件量測、工作面取樣及正反局部圖，交 Agent 複核；有證據的誤報可明示解除，不能因下一輪略過問題而解除。局部複核失敗會顯示原因，不執行缺少證據的模型修補。
- 同一來源修訂重新建立工作時，會帶入先前完成工作的未解問題；重新取得本轮證據，不重播舊修正命令。只有明確複核解除才移除，新的 Agent 漏報不等於通過。使用者需求／結構資料與技術修正失敗分開顯示。
- 低解析模式保留最後一輪可用預覽。有待確認項目時，即使選正式尺寸也只保留試圖，不直接啟動高解析。試圖通過後才出正式尺寸；正式成圖仍需人工看圖確認。
- 結果顯示每輪圖片、問題與修正，並提供前往材質／裝飾物／光源／觀看點的入口。按「採用本次預覽調整」才保存為新修訂；舊圖、模型與候選不清理。部分修正可採用，但待確認項目仍需處理。

## 自動修正範圍

| 問題 | 可執行的修正 | 保護與限制 |
|---|---|---|
| 亮度、光色、硬陰影 | 既有未鎖定光源的功率、顏色、大小 | 原始功率 1/4～4 倍，尺寸 1/2～2 倍；不移燈、不新增燈、不動環境設定 |
| 取景 | 既有效果圖 yaw／pitch／lens | 原始角度 ±45°／±30°、焦距 ±12 mm；觀看點位置與全景保持 |
| 取景裁切／主體不完整 | 從真實幾何計算構圖；效果圖可獨立後退至多 1.2 m | 核對地板、近身遮擋、移動線及主體可見性；保存於效果圖的 eye，360° 觀看點不動。02 的該方向顯示新鏡位並可回復 |
| 過度反光 | 單個子物件的原生材質粗糙度 | 複製材質，保留 UV、貼圖與其他節點；玻璃、金屬、連線粗糙度、複合材質及指定保留策略拒絕通用修改 |
| 家具位置 | 明確允許區域內水平平移，最多 20 cm | 不旋轉／縮放／刪除，原生組成包圍盒檢查不新增或加重碰撞；保留 keep-out；有承載物、裝飾依附或綁定燈具則不自動移動 |
| 水槽／洗手櫃安裝過低 | 依真實工作面及地板調整原構件安裝位置，增加側支撐／底座 | 不縮放原件，附著裝飾物同步，限制升高 3～60 cm；未知／估計尺寸才提出概念安裝高度，已確認尺寸／外框拒絕擴張；盆口不封住 |
| 桌／書桌／上下舖必要平板構件缺失 | Agent 根據局部圖與構件座標提出最多六片補件 | 保留原件與材質，XY 占地不擴張；已確認外框保持；不新增或加重外部碰撞。不是任意家具重建或施工安全認證 |
| 水槽缺支撐／龍頭外觀 | 受控平板或小型曲管概念構件 | 根據工作面及原占地定位，沿用原構件材質；不刪盆體、不封盆口、不聲稱給排水工程已設計完成。水槽支撐接至盆緣，不能把排水管最低點當成盆體承托高度 |
| 缺需求尺寸、結構洞口、缺貼圖或需換素材 | 列出具体原因與對應編輯入口 | 不猜成人床尺寸、不擅自開窗洞；尚未在此循環重新搜尋／替换所有資產 |

這是有限次、可追溯的視覺修正，不是全自動室內設計或施工驗收。Agent 的判斷也可能有誤；機器檢查及使用者確認仍分開保存。

安裝／後退鏡位需找到可辨識的地板群組（目前名稱含 floor／地板）；缺乏地板基準時保留問題，不假定世界 Z=0。修補碰撞目前採原構件包圍盒的保守檢查，可能拒絕外框相交但網格不相交的候選。鏡位候選依全部原生幾何核對，不會用隱藏牆壁來假裝取景改善。局部圖優先使用可用 OptiX，無可用裝置時才使用 CPU。

## 保存與恢復

沿用既有 LangGraph 確認節點、工作去重與單一重型佇列。`scene_review` 與模型選擇是工作內容的一部分；相同操作 ID 不會重複建立工作，不同內容不可共用 ID。

每案 `runs/interior-studio/<job>/` 保存 `scene-attempt-N/`（試圖、Blender 請求與日誌、Agent 回應）、`scene-review.json`（完整進度）、`scene-review-effective.json`（預覽採用設定）。有效設定附來源修訂與雜湊；採用拒絕過期編輯或模型變動。大模型不為每輪試圖重複儲存。

必要的原生構件修補會另建模型包（GLB／BLEND／物件索引／交接驗證），以 `scene_review_owner` 綁定出圖工作；只有最後有效且完成的模型可供 UI 讀取。未修改構件不刪除，修補失敗模型亦保留本機證據，本功能不清理舊資產。`diagnostics/` 保存局部圖片、構件／材質量測、射線取景候選與複核原文。

停止沿用現有按鈕，完成目前 Blender 圖片後停止後續；Agent 在收到事件時中止，另有任務逾時上限。服務重啟沿用既有工作程序核對，不重跑已提交渲染；外部程序確實中斷時保留試圖並需建立新工作，不宣稱自動從任意中間點續跑。

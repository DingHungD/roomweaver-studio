# 通用手繪確認與概念家具

所有者：系統功能文件。入口為根 README；現行圖片範例見 `examples/from-image/README.md`；合成回歸圖保留在 `tests/fixtures/legacy-examples/hand-drawn-study/`。執行產物與確認紀錄屬各自 workspace 案件，不放本文件目錄。

## 在 UI 內完成確認

1. **01 匯入 → 從圖片建立** 選自己的 PNG／JPG。Agent 只依這張圖與本案提供的背景盤點、複核，不讀其他案件或套用其答案。
2. 核對平面會依本次問題產生原圖彩框及問題清單。框是查找範圍，不是量測端點；無法定位會明說。可在原圖畫 A→B、填意思並保存。
3. **確認紀錄與答覆後修正** 新增來源／原文，選擇所回答的疑點；或帶入已保存的原圖答覆。只回答部分時，不勾「完整回答」。更正尺寸數字時，另選尺寸並填公尺值，不只寫自由文字。
4. 保存紀錄，再按「依確認紀錄修正」。Agent 引用紀錄提出新版；格式或越界問題會自動複核一次，仍不合格則保留原版並報錯。新版需由你開啟核對，確認尺度、直角條件與建模高度後才可建模。
5. 已確認值、原始誤讀、部分答覆及歷次來源保留追溯。不同版本的保存／答覆不能互相覆蓋；重送同一要求不重複執行，失敗或停止後可明確重試。未提交文字暫存於本機瀏覽器，正式證據仍須按保存。

這是通用工作流，不保證任意手繪圖都能自動辨識正確。模糊數字、無單位、未知端點與矛盾紀錄仍需回答。手繪比例不能取代實測，也不會為閉合而改寫确认數字。

### 手繪尺寸的判讀依據

首次辨識、放大複核及依確認紀錄修正共用同一原則：**數字尺寸優先，手繪線長只作相對位置參考**。Agent 沿水平對齊位置查找尺寸與牆段的關係，再核對尺寸線、引線、箭頭、端面及局部／總長／共基準；旋轉或縱向標註依其方向判讀。僅有對齊或鄰近關係不能冒充已確認端點。

來源轉錄仍保留像素位置，方便與原圖疊合；實際牆長需在幾何修訂中依明確對應的數值套用。單一比例尺不代表整張手繪已按比例。未明端點保持待確認，數值衝突個別列出，不為閉合或符合筆畫比例而改數字。此提示改進不會自動回寫既有平面，也不是新增的全自動尺寸求解器。

## 先確認家具區域

AI 空間配置先產生家具占位範圍、操作區及生活動線。採用後生成通用概念家具，保存需求承接及未解事項。本體碰撞、越界、必要家具缺漏仍會阻擋；僅有動線／操作區待調整事項時，可明確接受限制後進入概念編輯，不代表設計已驗收。依賴推導地板的路線仍不能採用。

**02 編輯 → 材質 → ＋新增概念家具** 支援椅子、書桌、餐桌、床、沙發、收納櫃、上下舖、洗衣機、爐具櫃與電視。設定尺寸與位置後加入，便可平移、改子物件材質、刪除、還原和復原。新增家具預設放在平面中心，可再調位置；加入不會自動通過動線驗收。

保存後重開仍在，Blender 出圖也包含新增家具。原始 GLB／BLEND 不變；目前設計由模型與修訂 JSON 共同組成，分享案件須保留完整 workspace。概念家具可在單物件展示中使用 [BlenderKit 配對與替換](BLENDERKIT.md)，由使用者選定候選後下載套用。

## 建模後的共用交接

用途確認後，牆與地板寫入明確角色，與 3D 匯入共用[牆地與家具分組標準](BLENDERKIT.md#共通匯入分組標準)。編輯以父群組操作、材質批次以群組搜尋；雙擊後保留子元件細調。家具區域各自成為獨立家具，不因類型或距離相同而合併。

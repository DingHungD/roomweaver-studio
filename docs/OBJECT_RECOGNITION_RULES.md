# YOLO候選的類別與完整外框判讀技巧

所有者：跨案件共用Roomweaver。執行版本`native-whole-object-v2`；正式提示與原生幾何實作在`object_recognition/native_policy.py`及`agent_review.py`，隨Studio部署，不依賴案件腳本或答案標註。

新CAD專案第一次「判讀圖面」預設勾選物件模型。整張原圖→YOLO全圖＋原尺寸／半尺寸640切片、25%重疊→合併候選→Agent核對CAD文字、幾何與周邊物件→來源外框修正→實際分類圖層全圖／六區查漏→既有用途、牆門窗與家具判讀。可取消勾選。Q/M反饋改走[物件／範圍局部補丁](PLAN_REVIEW.md)，延續同版物件，不重跑YOLO或整圖判讀；採用、3D與輸出維持原入口。圖片入口維持原預設；沒有CAD原生幾何不能偽造精確CAD外框。

| 狀況 | 判斷與處理 | 不應做的事 |
|---|---|---|
| 圖案相似、靠文字區分的方框設備 | furniture；文字／引線支持用途，床桌椅沙發等有特徵者保留細類 | 只取最近文字、讓每種文字都變新class |
| 水槽等有內外框的設備 | 找完整設備外緣，內盆不是整件 | 把盆底框當完整設備 |
| 櫃體旁邊緊貼黑牆 | 白色櫃體外框與黑牆來源分開 | 挑最大的外包矩形而吃入牆 |
| 同一窗或檯面由數段CAD表達 | 核對外緣連續性，bounds／edge_bounds涵蓋整件；內嵌設備可與檯面重疊 | 以封閉片段outline聯集，漏掉沒有獨立polygon的中間區 |
| 實心牆 | 相連為一件、斷開分件、保留凹形與孔洞；每段不能重複歸屬 | 把白色區域填牆、重複列同一短牆、用凸包抹平凹角 |
| 窗洞 | 窗各自獨立，窗處只標窗 | 推測補上下牆 |
| 樑與門洞 | 人工確認優先；門洞取相對門框邊線、樑取真實外框 | 因黑色而改牆、用包含牆端的大框當淨洞 |
| CAD未設closed旗標 | 僅當首末點完全相等且多邊形有效，衍生正規化為閉合，保存審計 | 閉合有縫圖樣、移動原始點 |
| 曲線椅背／家具 | 可用hull從同件原生點推導整件凸包占位，頂點均為來源點 | 混入桌線、填自由座標、將牆門窗套凸包 |
| 玻璃隔屏與開啟門扇 | 真正封閉實體投影聯集，共享原生鉸接點可支持同一組件 | 把開門弧與中間空白填成玻璃、丟掉互補門扇 |
| 高信心但輪廓有誤 | replace並引用原生refs；keep只保留當前版本 | 把confidence當成已完全正確 |
| 不確定、純文字或空白預留 | defer、保留來源與待辦；尊重本案確認 | 猜物件、刪不確定項美化分數 |

改類、大幅輪廓差異及未有充分重複證據的刪除仍受保守檢查；待辦／回查問題保留並阻擋採用。跨案技巧不能推翻本案人類確認。沒有參考標註時precision／recall為null，Agent認可不等於量化正確。

交接既有用途／建模判讀時，2D mask不直接轉成3D尺寸。家具elements省略不適用的thickness欄位，由既有格式處理；不能填0。燈具走lighting、平面樑等走drawing_objects，不為了表示平面圖樣建立零厚度家具。既有SemanticElement的尺寸限制、來源綁定與採用規則不放寬；交接提示只在啟用物件模型的分支加入。

模型輔助分支的格式轉接另存`handoff-pass-*.json`：只省略家具不適用的零thickness，圖樣layer由既有category_layer規則產生；不改分類、點座標、來源ID或牆厚，原始模型JSON另存不覆寫，仍經完整既有驗證。失敗後明確重試可只讀重用同案同平面已凍結的物件階段；來源、映射、單位、確認、影像、模型、類別表、政策及凍結檔雜湊必須一致，保留待辦與採用門檻。`recognition-resume.json`明示來源工作，不能冒稱重跑模型；來源有變則不重用。

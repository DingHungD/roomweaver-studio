# 空間與全案寫實化精修

共用功能入口為「03 整合輸出 → 寫實化精修 · Agent 試圖與回修」。範圍可選單一空間或全案所有觀看點；全案要求每個觀看點有至少一個效果圖方向。選擇已有方向的預覽起點，沿用建立出圖工作及確認渲染按鈕。先保存、確認編輯，才建立綁定修訂的試作；沒有專案名稱、家具 ID 或私人案例腳本依賴。

## 編輯與出圖的分工

- **02 材質**：家具用途、可用淨空、原模型與貼圖。新增「模型細節準備」，在彈窗沿用既有確認紀錄、選觀看點範圍，先準備未採用3D，不必先跑Cycles。當前支援可追溯平面洞口的門窗概念構件、具證據的單方塊層架及微波爐、咖啡機、雜誌；不是任意家具重建器。
- **02 裝飾物**：雜誌等生活內容；可使用同一準備入口，避免再做另一套素材下載器。既有新增／移動／刪除操作保留。
- **02 光源**：實際燈具綁定、日光與功率。此模型準備不改光源。
- **02 觀看點／03 整合輸出**：鏡位、畫幅與Cycles影像評估。不要用出圖調光補救錯誤尺寸，也不要為填空牆自動加未要求的裝飾。

模型準備是可重播的本機工作，綁定來源和修訂，結果只作唯讀預覽；未採用不更新保存設計。沒有已有層架設定時，Agent依原生可細化清單及使用者原文提案，再經相同證據驗證；缺證據會列出而不猜。準備工作不要求照明已確認，但需要觀看點定位範圍。渲染流程也會在有需求且尚無適配素材包時先跑相同淨空與匹配流程。

免費模型搜尋按用途與原始尺寸預篩，最多下載三個候選，逐件原生網格驗證，下載模型不縮放硬塞（僅容許0.1%浮點誤差）；失敗保留原因，找不到仍明示概念替代。素材清單、原檔、授權、網址與SHA存本案工作，修訂只保存工作ID，不接受Agent提供磁碟路徑。原生咖啡機／雜誌等已適配內容沿用，模型包隨候選重播，無須使用者再設定案件專用檔。

構圖候選增加左右偏轉及 **4:3／16:9** 橫幅，真實相機直接以該畫幅渲染，不拉伸或裁切既有成圖。效果圖預覽寬1024，分別高768／576；正式寬1600，高1200／900。全景仍為2:1。畫幅改變只屬構圖改善，不能宣稱表面品質或採樣改善。

搜尋同時保留細微角度與既有鏡位。低桌面不再被誤當地板或直接排除其上方鏡位，另外核對鏡頭淨空及移動路徑。相同來源、修訂與場景內容的純取景失敗會保存理由並排除相同參數，避免重複出無改善的圖；模型／材質內容改變後重新評估。幾何候選仍需真正出圖檢查，不能以低遮擋率宣稱構圖通過。

## 流程與採用

1. 讀取原生 BLEND，套用已保存的編輯與照明；從指定觀看點取樣六公尺內射線可見構件，檢查實際材質節點。未分房的 GLB 也不會直接把全案材質都列入修改。
2. 同修訂、來源雜湊、觀看點與原設定一致時，可沿用上次未採用且通過的精修預覽作比較基準；不寫入現行設計，UI 明示來源，來源變動則重新開始。產生固定鏡位基準：Cycles 64 samples、adaptive threshold 0.02、2048×1024 全景及 1024×768 效果圖。
3. 本機 Codex App Server 看圖與原生證據，提出受限材質／光源、窗景與效果圖取景修改；最多兩輪。UI 可展開「既有需求與本次精修重點」輸入物件名稱、既有用途與來源，隨工作及 checkpoint 保存，再次開案帶回；不改保存中的設計。最多 12000 字，當資料傳給 Agent，不作工具指令。每輪採樣、解析度與曝光相同，全景眼位固定；新增天花補面、等外框概念層架及效果圖取景變更另行標示，不能把構圖差異當作材質改善。
4. 與上一個保留版本比較；Agent 未判為更佳、亮度檢查失敗或超界時，不取代既有預覽。留存所有候選、原文、圖片雜湊及未解項目。
5. UI 顯示精修前／選出版本及完整紀錄。「採用精修並保存新修訂」才更新設計。過期修訂或模型變動會拒絕；採用後再確認、整屋檢查與正式出圖。

此階段固定輸出試作，不混在同一個工作直接跑 4K；避免把尚未確認的美術風格當作最終成果。用一般正式出圖即可重播已採用的精修參數。基本渲染仍不需要 Agent。

## 自動細化與邊界

- 保留每個物件的 UV、貼圖、材質來源與幾何；複製局部材質節點，在原有連線上增加顏色增益、粗糙度偏移、凹凸強度與毫米級 shader 倒角。倒角不是修改模型尺寸。
- 金屬、玻璃、透明、發光及無法安全解析的複合 shader 不套用通用精修；同個家具包含多個材質時只修改可判定的非金屬表面。使用者選擇保留／指定材質的物件受保護。
- 只調整觀看點附近既有未鎖定光源，或既有日光。功率相對初始 0.4～2 倍，大小 0.5～2 倍；不改位置、方向或曝光。日光會影響其他房間，UI 紀錄明示，採用後須檢查其他鏡位。
- 固定所有家具位置、尺寸、已知使用側與全景觀看點，不刪除必要家具、不自動清理任何模型。
- 跨房可見的構件可能被納入，這是「選定視域」而非經建築語義確定的房間界線；同一構件本身跨區時，材質也會影響其其他可見面。
- 原有設計疑點不因寫實化試作而解除。完整家具重建、基地實景匹配、貼圖替換、柔軟床品重建及 UV 尺度重鋪，仍會列在後續建議，不宣稱已自動完成。
- 布料：只有已知軟裝用途、原生 Fabric／cloth 等布料槽且可安全編輯時，才加入 0.3 mm 程序微紋理與 sheen；保留原貼圖與皺褶，不將皮革、金屬或塑膠改成布料。不保證在遠距預覽中看得到纖維。
- 櫃體：只為用途明確、原生單一方塊的櫃子加入正面門縫／周邊凹槽的 shader 細節；使用側依已知方向或相機相對位置推定，不改外框或內部構造。完整下載模型、多構件家具、用途未知占位不套通用門縫。這是表面細化，不能稱為完整訂製櫃。
- 窗景：辨認窗群組、外牆範圍與向外淨空，使用內附 CC0 城市 HDRI 遠景（來源及 SHA256 在 visualization/assets/manifest.json）。透過窗洞射線遮罩避免從未封閉牆頂露出；保留原 World、照明及原物件。遠景為示意，非基地照片或日照分析，無有限距離視差；窗框保持原生近景幾何。無法定位外窗時保留疑點。
- 天花：只在明確地板／牆壁分組下，從原生水平地板頂面取輪廓，檢查同楼层至少三面牆、80% 一致牆頂及八方向至少七個結構牆封閉命中（獨立牆體射線，燈具不誤擋）。只補完全缺少頂面的片區；既有含降板的全部或部分頂面、露天／挑空／陽台標記、高低頂不自動封頂。新增平面保留非矩形輪廓和原地板孔洞，向上射線再驗證。提供補面在全景中的可見位置與已套用標記，避免重複補同片或只靠名稱猜測。這是依既有牆頂推定的平頂候選，不是確認施工淨高；不改原幾何或必要家具。缺乏語義的中庭仍可能被誤判，必須看試圖、先預覽不自動採用。
- 取景：以原生家具網格建立主體可見性檢查，搜尋觀看點周邊有地板及淨空的鏡位；距原效果圖不超過 2 m。沙發取景同時保留鄰近茶几外框；按主體占比、遮擋比例、上半空牆、空地板、未知色塊與近景遮擋排序（空地板超過 25% 提高扣分），候選採較小下移軸並可上移，避免以空地板取代空牆，保留三個位置不同的候選。使用 20–35 mm、0、-4 或 -8 度俯角，另測試左右各8度偏轉及受限感光面平移，減少空牆而不刪茶几。每輪候選錨定初始設定，仍須實際看圖判斷美感；外框入鏡或低遮擋不能代替攝影驗收。
- 通用成品檢視準則：`src/interior/workbench/studio/realism_review_guide.txt` 隨套件發佈、每次 Agent 看圖實際讀取，包含先補空間缺件再修表面、燈具與天花關係、主體和茶几遮擋、空牆、窗外穿漏、材質尺度，以及「解析度不等於寫實度」。每輪保存準則快照與雜湊；出圖另記實際鏡頭位姿、焦距及移軸，避免把移軸後的地面占比誤當成俯角未套用，不依賴此對話或案件專用筆記。

- `render_finish`、`ceiling_infill` 與 `illustrative_exteriors` 保存在修訂 JSON；Cycles 執行時套用，原編輯模型保持；可從精修比較點「在02查看精修3D（尚未採用）」查看同次試圖輸出的幾何快照，包含天花與層架內容。Three.js 不完整模擬 Cycles shader 細節及窗景。採用不烘焙回原件。

## 資料及驗證

每次執行保存於本案 `runs/interior-studio/<job>/`：`realism-baseline/`、`realism-attempt-N/`、`realism-review.json`、`realism-effective.json`。這些是可重新執行的案件試作證據，不是正式交付；清理必須經既有使用者確認機制，本流程不主動清理。

合成測試：`tests/test_realism.py`；真正 Blender 材質／網格／UV 保全：`tests/integration/test_realism.py`。實際 Agent 案例另記驗證文件，不能用單元測試代替美術品質判斷。

## 用途證據與色偏修正（2026-10-14）

- 先讀使用者帶入的既有紀錄，不靠英文 ID 猜用途。可對原生单一矩形占位提出 `shelf_refinements`：Agent 引用必須是紀錄原文，包含精確物件名稱及書架／層架用途；外框、位置、已知使用側與原件保留。
- 原生執行器重新核對方塊頂點，生成兩側、背板與五個層板的四層概念層架，逐角點驗證全部留在原局部外框。出圖時暫隱原方塊，原 mesh、材質、資料庫來源不刪除。不是原指定下載家具，不含家電型號與安裝驗收；使用側未知則標示提案，不能假稱已確認。
- 需求改變或源模型已成完整家具時，不把完整家具重做層架。需求證據與產生物件清單另存 `shelf-refinements.json`。效果圖與全景都需看圖通過才保留候選，未採用不改現在編輯。
- 色偏先比較白／灰表面、灯罩與原生灯光 RGB；只調整允許的局部光源顏色與既有功率界限，保留鎖定與原材質。偏暖不等於白平衡已被測量，也不能保證僅中和燈光就改善全部反射。
- 精修紀錄加到現有出圖入口，不需要使用者執行案件腳本。通用規則與範例需求分開，核心無特定案件名稱與 ID。

原生材質證據另提供 `base_color_linear` 與發光節點顏色／強度：只追溯已知的色彩乘法包裝，遇貼圖或其他連線回傳 null，不猜測色值。Agent 須區分材料本色、燈光偏色與反射，允許同一視域的關聯光源一次試作；試圖沒有改善則退回較好版本，避免反覆只調單燈。色值是線性 RGB，不直接當作 sRGB 或測量色溫。


## 層架內容及未採用模型預覽

- `shelf_refinements.contents` 限微波爐、咖啡機與雜誌。同段需求證據必須含物件名稱與每一內容，不能用「書架」二字自動補入電器。四層內部分層放置，所有新增幾何重驗在原框內，不更改既有尺寸或移走必要家具。
- 選用本機原模型登記檔：啟動服務時設定 `ROOMWEAVER_REALISM_ASSETS` 為 JSON 絕對路徑。鍵為 `microwave`、`coffee_machine`、`magazines`；每項含 `file`（本機 BLEND）、`sha256`、`source_url`、`license`、`front`（+X/-X/+Y/-Y）。這是操作者管理的素材設定，Agent 不能提供任意路徑。原素材唯讀；工作請求快照保存登記內容。請保留原檔及登記版本以利重播，素材授權不隨程式 MIT 改變。
- 原模型保持 UV、材質及等比例形狀，不放大；若需要縮小超過15%或讀取失敗，列原因並改試明示的概念物件。概念物件仍有最低淨空，不足就回報 `needs_space`，不硬塞。這些是視覺配置，非家電散熱、承載或施工驗收。沒有登記檔的新專案也可用相同需求確認、淨空檢查與概念流程。
- 相機排序以實際細化後的層架網格檢查遮擋與占幅，同時降低大片空牆／地板，保留沙發與鄰近茶几；仍需 Agent 比較成圖，無安全更佳選項會保留原圖。
- 每次試圖輸出 `refined-preview.glb` 和 `preview-scene.json`。GLB 含已套用的幾何與位姿；唯讀場景清零位移旋轉、不再次生成概念家具，避免雙倍變換。GLB／場景雜湊與修訂、原模型綁定；過期或損壞拒絕載入。
- 02 預覽有明顯未採用標示、2D/3D切換和返回按鈕，不能移動、刪除或保存快照；原編輯仍可從返回按鈕恢復。GLB使用原有可用展示貼圖，程序材質／HDRI世界不保證等同Cycles。正式採用仍是獨立動作。

原素材的缺圖處理：先檢查連到輸出的貼圖。只有已確認為雜誌且材質名稱為頁緣（page）時，可在工作副本以中性紙張表面替代失蹤頁緣貼圖，保留封面原貼圖並記錄 material_repairs；未知缺圖不猜顏色，退回明示概念候選。

取景完整性改用原生評估網格的凸包支撐點（含附近茶几），不是方形外框空角；圓桌、斜放家具仍保留實際外形的安全邊界，避免空角誤限制焦距。遮擋仍以真正三角網格射線檢查，不能以凸包當作實際遮擋。


## 窗景保護與色偏診斷（2026-10-14）

- 取景先從基準主圖找真正可見的外窗；逐窗抽樣，核對視框與牆體遮擋。只保護原已可見窗，不強迫納入隔間後方的其他房間窗戶。候選鏡位保留這些窗景取樣點，以及沙發與鄰近茶几的實際網格外框；無符合者保留基準。
- 空牆、總地板與下方30%前景地板分開評分；兩種畫幅都允許受限感光面置中。幾何取樣比例不是圖片像素測量，最終仍由Agent對照同品質實際試圖。
- `realism_color.py` 對可編輯、已知單一暖色牆材提供有界色彩平衡候選，附原始／現行／提案線性色值；附近可編輯AREA光另提中性化候選。未知貼圖、木材、布料、混合材質及鎖定物件不自動套配方，實際是否修改由Agent判圖決定。
- 基準可見窗為同次比較的固定條件；缺少窗景保留證據的候選拒絕套用。不以較低空牆數字或較長焦距代替生活場景完整性。
- Agent設定記住使用者在此瀏覽器選定的模型；重新載入與跨案仍沿用。模型權限以實際任務為準，不可用時報錯，不自動換服務或模型。

- 有窗景約束時，另搜尋基準效果圖周邊25cm位移與較細角度，配合家具底邊的安全留白。鄰近沙發的茶几作為必要構圖背景，不再提出會裁沙發的茶几主圖；獨立餐桌／工作區仍可取景。
- 每次看圖附同一原生牆面的成圖sRGB中位數與R/B比值，取樣位置來自原生射線，詳細遮罩留在本機。這是色偏變化的輔助證據，不當成白平衡量測或美感通過條件。
- 同一來源綁定工作內，若只有鏡頭、燈光及非幾何材質精修變化，重用基準取景候選；模型、家具、層架內容或天花設定變動則重跑幾何搜尋。候選仍重新試渲染與判圖，並非沿用舊成圖。

- 圖片辨識、確認紀錄修正、空間配置與編輯／出圖共用同一模型偏好；讀取舊任務不覆蓋目前選擇。所選模型不在清單或不支援圖片時明示錯誤，等待使用者明確選擇。
- 判圖節點是無工具的分析／提案工作，模型回傳受控修改，由主程式執行、渲染與重驗；只有實際提供MCP的任務才要求使用指定工具，避免把缺工具誤判成不能提出修正。

## 全案與門窗（2026-10-14）

- **01 匯入**：新 PNG/DXF 建模在已核對洞口內建立完整窗框、玻璃、門框與概念門片。洞口位置、高度和寬度沿用平面建模設定；不把預設高度提升為使用者確認。開門方向、鉸鏈、型材與產品型號仍須有需求證據。
- **02 材質 → 模型細節準備**：既有平面轉3D模型可勾選補齊門窗。後端只追溯目前模型祖先的 confirmed-plan 與實際建模 request，重算一致才使用；原生宿主被刪除、洞口被牆堵住或範圍不符時逐項列原因。不另切牆、不更改原件。直接 GLB 缺少可信洞口資料時不猜測開洞。
- **03 全案精修**：同一次 Blender 場景生成所有設定觀看點的試圖，Agent 分空間看實際全景及效果圖。相同 shot ID 以觀看點區分；共用構件提案衝突保留目前設定，不以最後回覆覆蓋。候選只有在所有受檢空間均未退步、至少一處改善且亮度檢查通過時保留。最多兩輪，逐空間摘要與原圖雜湊留存。未設觀看點的區域不宣稱已檢查。
- **02 預覽同步**：選出試作的同場景 GLB 供唯讀檢查，可切換各觀看點；生成門窗各自為單物件。只有使用者採用才寫新修訂。玻璃、窗景及光照效果以 Cycles 為準。

01→02→03 已有可接續的 Agent 工作，但不是任意輸入的無人全自動設計：平面疑點與尺寸、用途不明、照明及觀看點確認、最終採用仍保留使用者決策；基本渲染也不強制呼叫 Agent。工具不自動清理舊模型。

補齊門片後，原來在門洞外或距物件少於16cm的效果圖鏡頭可能受遮擋。取景搜尋可從同觀看點既有全景眼位恢復，仍驗證地板、鏡頭淨空、路徑與完整主體，不穿牆或搬家具。取景主體涵蓋床／上下舖、浴櫃、洗槽、爐具與衣櫃；幾何變更後重新生成候選。

取景搜尋先用完整主體投影篩選，再對有界候選做原生網格射線，避免每個細角度都重算。中間透明玻璃允許看見外窗；實心構件仍阻擋。跨空間試作可保留上輪局部改善再修正退步項目，但正式候選仍須全部受檢空間比較通過；未採用試作不能覆蓋已選出的較佳版本。

逐空間判讀若選回基準、且沒有通過驗證的新鏡位提案，下一輪自動恢復該空間較佳版本的效果圖鏡位再試圖；不能把「保留基準」當作不做事，卻繼續帶入剛被否決的構圖。其他空間的試作及材質修整可保留，但仍需共同重驗。

### 同一使用區的完整取景

候選搜尋將床／桌椅／衣櫃、廚房設備、沙發／桌子等用途關聯與實際距離、隔牆射線一起核對；不靠案件名稱或固定座標。相關物件一起參與原生網格完整入鏡、遮擋及構圖評分，不能藉單件特寫漏掉同區設備。無安全候選保留問題，不能移除必要家具或更改尺寸。

保留既有窗景與新增示意室外景使用不同條件：保留依現有照片中可見的窗洞採樣，不受整屋矩形外框或窗外障礙限制；新增室外景仍須外窗與室外淨空證據。混合玻璃與窗框的網格依射線命中的實際面材質判斷透視，不能因其他槽是木材就忽略整片玻璃。

整組取景無安全解時，原生搜尋可提供獨立 `coverage-*` 互補效果圖；經 Agent 選擇、試圖比較後才列入未採用預覽。原主圖、窗景、全景眼位和家具不變，重播使用穩定 ID 不重複新增。鏡位射線忽略 hide_render 的舊替換構件，仍保留真正會渲染的牆體／家具遮擋檢查。

02 唯讀精修預覽可切換同一空間的各效果圖方向；以36mm感光面、畫幅與垂直移軸對應 Cycles 取景，將畫框放入未被工具列遮住的區域。一般編輯導覽保持原設定，程序材質與即時照明仍非最終渲染。

取景評分將主體與周邊家具分開：另以主體原生網格射線量測茶几等周邊家具造成的遮擋，主體超過60%被遮或不足3個採樣時排除。前景以相對主體距離檢查近側物件與邊緣櫃側，不限固定75公分；完整外框仍須保留。低於24mm增加排序扣分，保留狹小空間廣角作總覽，但提供較自然的設備互補候選。這些採樣是初篩，必須再經實際試圖比較。

既有 `coverage-*` 圖只由對應物件的候選修正，書桌保留座椅作完整入鏡條件；不把整房家具再次塞入每張互補圖。既有互補圖可見窗景仍受保護，原主圖及必要家具不移除。規則依用途、實際幾何與穩定物件 ID，沒有案件名稱、固定座標或特製結果。

候選供判圖時交錯保留綜合評分、較少主體遮擋與較少上半空牆的安全解，每方向最多6個；相近位置但眼高相差12公分以上仍可供比較，避免把茶几遮擋改善的高度變化當作重複。排序取捨不代表自動採用，既有失敗鏡位與實際成圖比較仍生效。

整屋只有相機修改、其餘場景內容完全相同且每個空間都有完整判讀時，可保留各空間最後判讀為 candidate 的效果圖設定，其他空間用較佳基準；組合後重新出圖與產生02快照。共用光源、材質、幾何、全景眼位或空間身分有任何變化都禁止混合。接續同來源同修訂的舊整屋工作，也能從其最後已通過品質檢查的實際試圖恢復這些獨立鏡位，再進行新試圖；保留原報告與失敗試圖，不回寫歷史判讀。

失敗鏡位依各房間最後實際比較追蹤：整屋工作中的個別房間否決結果能跨到單房續跑，並從當輪實際場景與比較基準的差異取得鏡位，即使該鏡位是上一輪留下、未出現在本輪 changes 也能排除。整屋未獲選不代表所有房間失敗；已通過的房間不列入黑名單。場景材質／照明／模型內容不同時不沿用失敗記憶。

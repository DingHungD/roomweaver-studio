# 門編輯

02 編輯 → 門：左側維持 2D／3D；右側為 +新增門、一鍵配置、復原上一步。

## 便籤式詳細編輯

- 2D 平面圖與 3D 畫面：右側分為「主畫面、其他門」。名稱固定在頂部；主畫面保留門型、門組 AB 長度、開口／旋轉方向、折疊端、刪除／還原與門寬試算。門洞端點與原尺寸收在「門洞端點與尺寸」，其他門分頁提供搜尋與選取。
- 3D 單物件展示：右側分為「主畫面、材質、AI 設置、候選清單」。主畫面保留上述門控制與目前素材來源；材質頁選門框／門片、調基本色及粗糙度，或改回基本材質；AI 設置保留配對目標與需求描述；候選清單沿用授權確認、下載檢查、未保存預覽與明確套用。
- 點選 3D 門框／門片會進入材質分頁；搜尋新候選後進入候選清單。頁籤可用左右方向鍵、Home／End 切換。
- 切換詳細分頁只改可見內容，保留同一畫布、模型與配對元件；描述草稿、選定候選及授權勾選不因切頁消失。切換不同門或部位仍載入各自的既有候選；修改幾何後仍照原流程在背景核對姿態。
- 不變更保存格式、已確認尺寸、開門方向或下載／碰撞檢查規則；替換仍須檢查成功及使用者明確套用，不會因切頁自動採用素材。

本機驗證：`artifacts/door-detail-20261020/`，含正式元件合成測試與目前案件的唯讀畫布／請求量測。候選介面合成測試不等同實際下載、Agent 判讀或 Blender 出圖。

- 點「+新增門」，在平面點 A、B 兩個門洞端點。新增定位不預設種類或方向；高度暫為 2.1 m，不代表施工確認。
- 名稱可自行修改；種類為單開門、雙開門、拉門、只有門框、折疊門。
- 單／雙開門選 A→B 左或右法線側；只有單開門選順／逆時針。平面顯示門片與開啟弧線，3D 顯示輕量概念門型。
- 新增門不會切除原牆。正式建模會核對開門碰撞，受阻會保留門並回報；即時概念預覽不是施工或碰撞通過證明。
- 一鍵配置使用 gpt-6-sol，讀取同案可追溯平面門洞、人工定位及平面家具關係；不改端點尺寸。對不支援或不確定門型留下疑點，折疊門保留原門型；可選折向側與 A／B 收折端，兩片連動以 80° 概念開啟姿態預覽；正式建模另檢查門板相互干涉與 12 段掃掠碰撞。只有 GLB 且無平面門洞來源時，需先兩點標門；目前不會憑空猜牆洞並切牆。
- Agent 結果進入未保存草稿；配置期間若設計被修改，拒絕覆蓋。保存仍採既有版本檢查；復原沿用原編輯歷史。
- 預覽由獨立門型／SVG 圖層更新，不重新載入 GLB 或更換材質。首次載入先預熱 3D shader，避免第一次切換的編譯卡頓。

資料：Scene.manual_doors 保存新增端點；door_controls 保存名稱、種類、側向、旋轉。原始門洞與原件不改寫。GET 模型 doors 取得來源；POST projects/{project}/doors/design 啟動可查詢的 Agent 任務。

驗證：tests/test_door_design.py、frontend/tests/studio-door.test.mjs、tests/fixtures/scene-review/check_door_types.py；另執行 check_openings.py 回歸碰撞／門窗。實際 UI 證據在 artifacts/door-editor-20261016（本機驗證，不隨開源資料發布）。

折疊門一鍵配置在 Agent 提案後，以原生工作模型核對12段收折路徑和門板自相交；未人工指定的方向受阻時最多改試 A/B × 左右四組。人工指定方向保留並回報疑點，不改門洞尺寸、不保存原生檔。即時操作先顯示暫定門型，背景自動執行原生碰撞檢查；完成後用原生頂點更新2D／3D。

門頁提供 3D 單物件展示：以選取門為中心隔離門型預覽、拖曳旋轉與縮放；新增的門尚未指定種類時顯示定位框。詳細編輯可刪除／還原門，使用修訂中的 deleted 設定，不刪原件。已刪除門排除預覽、Agent 配置與原生補建；復原上一步可恢復。原生門型預覽與素材配對的下載／採用分開處理。

門的單物件展示可點選門框／門片，或用子物件清單選取，分別修改基本色與粗糙度。覆寫按 frame、leaf-0、leaf-1 保存於 door_controls.materials；2D 門符號、3D 門型和 Blender 生成門共用。顏色由 sRGB 轉線性後交給 Blender；不改尺寸或開向。雙擊平面門標記／線段或3D門片可進入單物件模式。基本色與粗糙度在「材質」分頁調整；需要原生貼圖或門片模型時，使用「AI 設置」與「候選清單」的門專用配對流程。


## 原生姿態同步（2026-10-16）

門頁自動呼叫 `POST projects/{project}/doors/poses`。以目前模型、群組位移／刪除、手動門與門控制建立唯讀檢查副本，使用與出圖相同的 `add_openings`。結果包含實際門片／門框／五金頂點、開啟狀態及阻擋物。2D輪廓與3D單物件直接取用這些頂點，不另猜拉門收疊方向。檢查期間標示「暫定姿態」；失敗顯示原因，不冒稱已通過。

- 單／雙開門完整掃掠受阻時，保留指定開向，採用已驗證的最大取樣角度（至少15°），標示 limited 和使用淨寬待確認。沒有安全取樣則保留關閉姿態。12段取樣不是連續碰撞或施工驗證。
- 拉門沿既有兩軌收疊，包含碰撞選定的軌道偏移；不改門寬、高度與材質。
- 背景結果以模型雜湊、來源與設計快照快取到案件 runs/interior-studio/door-poses；切換選取及修改門色不重跑 Blender。改變幾何後失效，舊請求不得覆蓋新畫面。算法改版須更新快取 version。
- 基本姿態檢查不呼叫模型，也不需要 Codex 登入；Agent仍用於一鍵配置提案。背景檢查不阻塞前景操作，但首次原生檢查可能數秒，不能等同500毫秒內完成碰撞計算。
- derived pose 不寫入原生模型或正式修訂，出圖重新從相同設計運算。未採用精修模型維持唯讀預覽。


## 逐門授權寬度適配

單開門可勾選「允許 Agent 微調門寬」，預設關閉；通行投影目標預設70cm，可調整，這是概念配置目標而非施工／法規標準。按一鍵配置後先由實際模型檢查鉸鏈、把手與掃掠，再向 gpt-6-sol 提供證據。已授權門由原寬起每1cm最多縮15cm，選擇完整開啟且符合目標的最寬候選；沒有候選就保留原件並說明。模型文字不能繞過實測或更改未授權門的尺寸。

保持來源門洞端點、中心、開向及高度；試配框寬保存在 door_controls.assembly_width，兩側以門框同材質固定收邊填滿原洞口。不得直接縮門片而留下裸縫。單開／雙開鉸鏈軸位於開啟側門片表面，避免中心軸造成不必要的邊緣掃牆。2D與3D仍取用原生姿態頂點，原模型不覆寫。

這是有限範圍概念試配；較窄通道的搬運、無障礙與實際五金規格仍應按案件需求核對，不以碰撞通過宣稱方便所有人使用。

Agent服務不可用時，可用同一面板的「預覽門寬試算（Agent待確認）」查看共用碰撞引擎的候選。此操作明示 Agent 尚未判讀、不代表完成設計審查；結果為未保存草稿，採用仍需保存。不得因服務滿載而靜默切換模型。

## 單物件素材配對

門的單物件視圖提供需求描述、BlenderKit 免費優先候選與來源網址。門框僅換材質；門片可換材質或單片模型。含可識別門框的模型先排除框體，無法確定用途、尺寸適配或開門掃掠受阻時拒絕套用，不把整組門硬縮到門洞。門洞、開向、種類及已確認尺寸仍由原有參數控制。

搜尋採短用途詞，精確尺寸留給下載後檢查，不用毫米數字限制素材庫搜尋。下載後先檢查，使用者按「套用並檢視門素材」才保存新修訂。候選與來源保留；本流程不清理舊模型。

案件 `workflows/interior-studio/door-assets/` 保存配對、下載來源與雜湊、待套用提案；原生模型引用此同案素材包，渲染前檢查雜湊。`runs/interior-studio/door-poses/` 保存可重建的姿態與 GLB 預覽。兩者不可混同為同一份採用設定；採用權威仍為場景修訂。備份案件須包含素材包。

有素材時，門的 3D 預覽由同一套原生門組件輸出，背景更新；不將素材載入的延遲算成互動按鈕已完成渲染。材質為原生節點，網頁使用可匯出／烘焙近似預覽；正式出圖使用原材質。原始簡化顏色控制會在套用素材時停用；「改回基本材質」可回到參數色。

## 未完成項目定位

清單可按「Agent 依原因修正」；已確認尺寸及開門方向鎖定，仍受阻便保留原因。詳細編輯另有手動「門組 AB 長度」，五種門型均可在原洞口內居中縮短，保留開向與材質、以同材質收邊，不擴大來源洞口。詳見 [未完成修正流程](EDITOR_REPAIR.md)。

工具列右側常駐「查看未完成項目（數量）」，即使為零也保留。門頁合併現有種類／開向檢查、原生姿態受阻與配置／素材任務失敗，每扇門只列一張卡片。點卡片或畫布編號框會定位原門洞並展開右側詳細編輯；有明確失敗子物件時保留門框／門片識別。定位不更改尺寸、方向、材質，也不另建占位模型。

`GET /api/studio/projects/{project_id}/editor-issues?revision=...` 只讀案件既有任務及檢查結果，不恢復流程或啟動 Agent。新門配置任務指標保存於 `workflows/interior-studio/doors/current-design.json`，門素材沿用既有 current 指標；舊版未留指標的歷史門配置不臆測補入。觀看點僅讀同修訂、同模型最新有效整屋檢查的取景待處理項目；新報告清空 pending 後不復活舊問題。失去目標識別的工作會明示無法定位，不指向第一扇門。
